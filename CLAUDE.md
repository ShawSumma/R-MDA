# r-mda

RWKV-7 G1 (imported from BlinkDL's weights) trained as a block-diffusion text model jointly with AR, optionally distilled from Qwen3.8-Flash-Next through byte-level targets, in raw Vulkan compute (C host + GLSL).

## Rules

- Run `build/bench` before and after a performance change; its per-kernel GPU profile says where the time goes.
- Any buffer the host reads back is `mda_vkc_alloc_cached`; bulk host reads of device-local buffers go through a cached staging buffer and `mda_vkc_copy`.
- A change to what the parameters mean (their order, or a formula that reads them) bumps `MDA_CKPT_MAGIC` in src/ckpt.h; the header only catches config and layout-size changes.
- The student's tokenizer is RWKV's World vocab (`tools/world_vocab.py` writes `models/world.txt`); the teacher's is Qwen's BPE (`tools/bpe_vocab.py` writes `models/qwen.txt`). After changing the corpus, the token-id cache rebuilds on the next load. Checkpoints trained on another vocab are refused.
- If train stops with "overflowed", run `build/probe_acts` on `models/ckpt-overflow.bin` before changing anything.
- Python tools run from `.venv` (pyarrow is installed there).
- Compare training changes with `tools/logstat.py` on runs from the same seed: batches are a hash of the step, so the runs are paired.

## Style

- C17 (`-std=gnu17`), no C23 features: `bool` comes from `<stdbool.h>`, no typed enums, no `{}` initializers.
- Every name carries the namespace `mda_` plus its file's name: `mda_fwd_rec`, `mda_fwd_act_t`, `MDA_MODEL_MAX_PARAMS`; a program's own functions use its file name too (`mda_train_lr`).
- Headers hold, in this order: includes, defines, typedefs, enums, structs, prototypes. `.c` files hold only includes and functions. Order declarations by dependency and use, not alphabetically.
- An enum is a `typedef uint32_t x_t;` in the typedefs plus an anonymous `enum { ... }` of its constants after them; never a typedef merged with the enum.
- Struct members are laid out to avoid padding, with bools last.
- No comments (C, GLSL, makefile, Python). No `static`, `inline`, function bodies in headers, `exit()`, ternaries, `++`/`--`, out parameters, `qsort`, `rand`/`srand` (pseudo-randomness comes from `src/hash`), or plain `int` (except `main`).
- No side effects in a condition, including calls that write or print. No reassigned status flags. No guard clause that returns and falls through to more code: when one branch returns, the rest goes in `else`; split long functions into stages instead of nesting.
- Use `switch` to dispatch on a value. Each call and signature sits on one line, or one argument per line with the closing `);` on its own line.
- printf padding only in tables with a header row; no decorative output.
- The makefile uses `!=`, `${VAR}` and `${VAR:%.c=%.o}`, not GNU functions or `:=`; header dependencies come from the compiler (`-MMD -MP`).

## Code structure

- `makefile` -- `shader/*.comp` -> `build/*.spv` (glslc); the modules in `MODS` -> `build/obj/*.o` -> `build/libmda.a`; each program in `PROGS` (`src/<name>.c`) -> `build/<name>` linked against it; `build/**/*.d` hold the header dependencies. `make test` runs every `build/test_*`. Binaries load `build/*.spv`, `data/corpus.txt` and `models/` by relative path, so run them from the project root.
- Errors return to `main` as `false`/NULL/`ok` results: a Vulkan or config failure sets the sticky `mda_vkc_t.fail` (every vkc call is then a no-op).
- `tools/fetch_corpus.py` -- downloads a mixture of parquet text datasets (`SOURCE=GB`: fineweb-edu, dclm, finemath) into `data/<source>/` and writes every document followed by a blank line to `data/corpus.txt`; run it with `.venv/bin/python3` (pyarrow).
- `tools/fetch_hf.py` -- resumable, parallel stdlib download of a Hugging Face repo's files.
- `tools/pth_to_safet.py` -- a torch `.pth` state dict to safetensors (stdlib, compact header).
- `tools/world_vocab.py` -- RWKV's World vocab to `models/world.txt` (zero merges: greedy longest match).
- `tools/bpe_vocab.py` -- a Hugging Face byte-level BPE `tokenizer.json` to the tokenizer file format (vocab bytes in id order, added tokens included, merges as "left right merged" ids); refuses BPE options the encoder lacks.
- `tools/gen_unicode.py` -- writes `src/unicode.c` (the letter, number and mark code point ranges the Qwen pre-tokenizer regex uses) from Python's unicodedata.
- `tools/safet_header.py` -- lists a safetensors file's tensors (name, dtype, shape).
- `tools/check_rwkv.py` -- compares `build/check_import`'s logits with a torch reference RWKV-7 forward on the original `.pth`.
- `tools/check_qwen.py` -- compares `build/check_qwen`'s logits with Hugging Face's Qwen4-Exp text model run one decoder layer at a time in fp32 on the CPU from the shards (n-gram embedding looked up row by row, the QSA indexer bypassed, which is exact below its budget), and our token ids with Hugging Face tokenizers; needs the reference venv (`.venv-ref`: torch, transformers with qwen4_exp, tokenizers).
- `tools/logstat.py` -- mean loss and bits/byte over a window of steps of `build/train` logs (`--last`, `--end`).
- `tools/compare.py` -- one `build/train` run per variant with shared settings, each then evaluated by `build/sample`, and a table of the results.
- `tools/vast_wait.py` -- polls a vast.ai instance (through the `vastai` CLI in `.venv`) until it runs, then prints its ssh addresses.
- `tools/strip_ckpt.py` -- copies a checkpoint's header and weights into a weights-only file.
- `src/vkc` -- Vulkan harness: device selection + feature checks (cooperative matrices, buffer and shared float atomics, wave32, clustered subgroup ops), device-local (`mda_vkc_alloc`, never mapped, counted in `dev_bytes`) vs host-cached (`mda_vkc_alloc_cached`) buffers, views, copy/fill, `mda_vkc_read`/`mda_vkc_write` (a whole buffer to or from the host through a staging copy), kernel loading, dispatch (refused when a binding exceeds `maxStorageBufferRange`, 4 GB on NVIDIA). `mda_vkc_begin`/`mda_vkc_flush` record a transient batch into one submit, `mda_vkc_record`/`mda_vkc_end`/`mda_vkc_submit` a persistent command; outside a batch every `mda_vkc_run` is its own submit + wait. Also the per-kernel GPU timestamp profiler.
- `src/pc.h` -- push-constant layouts of every shader, `MDA_PC_NO_SLOT`, the vecops ops.
- `src/hash` -- pure hash of (stream, key, index) to integers, uniforms and normals.
- `src/sort` -- heapsort of (key, index) pairs, ties broken by index.
- `src/util` -- clock, path suffixing, argv defaults, ok/FAIL, min/max.
- `src/unicode` -- generated letter, number and mark range tables and their binary-search lookups.
- `src/tokenizer` -- tokenizer file read and two encoders: with zero merges (World) greedy longest match over a byte trie (id 0, end-of-text, never matches); otherwise byte-level BPE (merge table by open addressing on the id pair) after Qwen's pre-tokenizer regex (case-insensitive contractions, a letter/mark run with one optional leading non-newline non-letter, single digits, punctuation runs with an optional leading space and trailing newlines, whitespace up to the last newline, then the GPT-2 space rules), lowest-rank merge first. No NFC normalization, so byte offsets stay those of the text. Tokenizer hash, padded vocab size, corpus and vocab paths.
- `src/data` -- loads the World tokenizer and tokenizes the corpus on every core into `data/corpus.txt.ids` (reused while tokenizer and corpus are unchanged; last 1% held out as the eval split); threads and windows are cut only where a printable ASCII byte meets a newline. `mda_data_batch` fills a batch (ids, target, mask, loss weight) as a function of its key (`(step - 1) * accum + micro + 1`), so a run is reproducible and a resume never replays batches. Schedules: `BELL` (diffusion training: t from a truncated N(0.5, 0.1), unweighted loss), `ELBO` (evaluation: t uniform on (0, 1], 1/t weight, so the loss is the NELBO), `AR` (next-token targets, nothing masked).
- `src/safet` -- safetensors reader: files mmap'd, bf16 and i64 tensors by name (any rank, rows = product of the leading dims), bf16 copies into fp32, HF linear [out, in] -> [in][out]; a shard set (`mda_safet_open_set`, from `model.safetensors.index.json`'s shard count) searched by name.
- `src/model` -- config (`mda_model_cfg`: RWKV-7 G1 2.9B's shape, d 2560, 32 layers, 40 heads of 64, FFN 10240, low-rank widths w 96 a 96 v 64 g 320 padded to multiples of 64 (the zero padding is exact), vocab padded to 64; checked by `mda_model_init`), parameter registry (`mda_model_param_t`: views of w, g, AdamW moments and fp16 mirror into per-role arenas, plus the transposed fp16 mirror), the per-layer low-rank MLPs (`mda_model_lora_t`), kernel handles, the KD switch and weight.
- `src/fwd` -- the GPU optimizer state block (`mda_fwd_opt_t`), scratch buffers (with the host batch view of the inputs and the KD inputs), per-layer saved activations (`mda_fwd_act_t`), dispatch helpers, mirror refresh, and the one forward (`mda_fwd_rec`) shared by training and inference; `mda_fwd_run` wraps it for eval/generation. The block is official RWKV-7 G1: LayerNorms with bias (ln0 after the embedding, ln1/ln2 per layer, ln_out before the untied head; eps 1e-5); six token-shift mixes x + (prev - x) * mix for r, w, k, v, a, g; r, k, v from full matrices, w, a, the value-residual gate and g from low-rank MLPs; `heads_fwd` makes decay w = exp(-0.6065 sigmoid(w0 + .)), a = sigmoid(a0 + .), the value residual v + (v_first - v) sigmoid(v0 + .), the removal key kk = normalize(k * k_k), the replacement key k * (1 + (a - 1) k_a) and the bonus; the recurrence S'[i][e] = w[i] S[i][e] - a[i] kk[i] (S^T kk)[e] + k~[i] v[e] (`wkv7_fwd`: one workgroup per sequence, head and direction, clustered subgroup sums, fp32 state saved every 4 steps); `wkv_out` per-head GroupNorm (eps 64e-5, affine) + bonus, times g; FFN value(relu(key(shifted x))^2). Vectors of a layer are bound through one per-layer view and large arenas are cast and summed in chunks, so no binding passes 4 GB. The loss pass (`softmax_ce` op 0) keeps each row's logsumexp and its gradient's absmax; the backward writes the logit gradient to fp16 (op 2, op 1 in fp32 for ref32), adding the KD gradient on the clean rows. With `mda_model_t.causal` only the left-to-right wkv pass runs (an AR model). A config with `block` (`block` / `block<n>`) is block diffusion jointly with AR: the batch's first half holds the second half's windows unmasked, run causally with next-token targets; each noisy block's left-to-right wkv pass starts from the clean rows' state at the block start (`bstate`, gradient through `dbstate`); `block<n>d<D>` splits it into encoder and decoder with shared weights. With `cache` set the clean rows continue from a cached state, so a block-length model decodes one block at a time exactly as the full-length one.
- `src/bwd` -- matmul backward helpers and the fp16 matmul (`mda_fwd_mm16_epi`: layouts `MDA_FWD_AB`/`AT`/`BT`, output stage `alpha * AB + beta * prev` stored fp32, fp16 or both, optionally symmetric; 128x128 tiles when that gives at least `MDA_FWD_WIDE_GROUPS` workgroups, else 64x64; k a multiple of 32, offsets 16-byte aligned).
- `src/step` -- `mda_step_trainer_t`: three persistent commands, forward + backward writing the grads (first micro-batch) or adding to them (the rest), and the optimizer (grad norm, clip, dynamic loss scale with overflow skip, Muon on r, k, v, o and the FFN matrices or AdamW alone). With KD on, `kd_student` runs between the loss pass and the head backward. The KD loss per clean row is reduced on the host (`kd` in the log, nats per clean token).
- `src/ckpt` -- checkpoint format (header with config + vocab hash, then the w, m, v arenas, or w alone in a weights-only file), atomic save, validated load; `mda_ckpt_shape` copies a checkpoint's shape into a config.
- `src/qwen` -- the Qwen3.8-Flash-Next (qwen4_exp) text model as a teacher, streamed layer by layer from the mmap'd shards: a loader thread copies the next layer's bf16 weights into one of two pinned staging banks (16 copy threads; dense matrices concatenated per projection and zero-padded to 128-row tiles, the 512 experts' gate_up and down tensors as they are) while the GPU runs the current layer; each bank is copied to the GPU and converted to fp16 in place, then every chunk of rows runs the layer. A pass is bound by disk reads when the 360 GB of weights are not cached, so passes should be as large as GPU memory allows. Hidden state: 4 hyper-connection streams in fp32 for all rows. Layer: (layer 1) PLE: hashed 2- and 3-gram ids per token on the host (multipliers, prime sizes and offsets read from the checkpoint), rows gathered from the 128 n-gram shards, key/value projections, grouped RMSNorms, the sign-sqrt gate per stream, a dilated causal conv; then the attention hyper-connection (grouped RMSNorm with 1 + w, low-rank mixer, injection weights), either Gated DeltaNet (one projection for qkv, z, b, a; causal conv + silu; l2-normalized q, k; `qwen_gdn` runs the delta rule one workgroup per sequence and value head, each lane one state column) or gated attention (q with its sigmoid gate, per-head RMSNorm, partial RoPE on 64 dims, causal GQA in `qwen_attn`; the QSA indexer is a no-op below 2048 tokens and not implemented), the injection into the streams, the MLP hyper-connection and the MoE (router softmax top-10 renormalized, rows sorted into 128-row expert segments on the GPU by `moe_route`/`moe_scan`/`moe_scatter`, `matmul_f16_moe` with a per-tile expert, shared expert with its sigmoid gate, `moe_combine` with the injection). The head (final mixer + lm_head) runs in sub-chunks of `head_rows` and hands each sub-chunk's logits to a sink callback. Sequence length a multiple of 64.
- `src/kd` -- byte-level KD data: the token-string table the KD kernels read (first 16 bytes + length per id, specials zeroed), a training window's text and token end offsets, the KD file (header, window index, per window one 8-entry record per byte: the teacher's probability of the true next byte, then its 7 likeliest other next bytes, fp16 in the high half), mmap'd reading.
- `src/teach.c` (+ `teach.h`) -- `build/teach [from [to [out [windows [mode [batch [accum]]]]]]]`: KD targets for the clean rows of training steps from..to-1 (defaults 1, 2, `models/kd.bin`, 32 windows per pass, block16, batch 2, accum 8; the windows are exactly the trainer's): each window's World tokens become text, Qwen-tokenized into a 384-token sequence; the teacher's logits at each row go through `kd_bytes`, which conditions its distribution over the next teacher token on the window's true bytes to get the next-byte distribution at every byte inside that token (up to 16 deep). Prints the teacher's bits/byte on the true bytes and the time left.
- `src/train.c` (+ `train.h`) -- training loop: warmup-stable-decay lr, logging, checkpoints every 30 minutes and at the stop step, resume; `build/train [lr [checkpoint [stop [accum [adamw|muon [diffusion|block<n>[d<D>]|ar [batch [kd [kd_weight]]]]]]]]]` (defaults 3e-4, `models/ckpt.bin`, no stop, 2 micro-batches of 8 sequences, muon, diffusion, no KD, weight 1). With a KD file each micro-batch's clean rows get, per position, the bytes of the next token (up to 16) and the teacher's targets at those bytes; `kd_student` computes the student's next-byte distributions the same way from its own token distribution and adds weight * KL(teacher || student) per byte, with buckets the student cannot produce dropped and the teacher renormalized.
- `src/import.c` (+ `import.h`) -- `build/import [weights [out]]`: a checkpoint (step 0, zero moments) from RWKV-7 G1 safetensors (shape read from the file, low-rank matrices zero-padded); defaults `models/g1/g1k-2.9b.safetensors` -> `models/g1k.bin`.
- `src/check_import.c` (+ `check_import.h`) -- runs an imported checkpoint causally in fp32 on the start of a text and writes ids and logits to `models/import_check.bin` for `tools/check_rwkv.py`.
- `src/check_qwen.c` (+ `check_qwen.h`) -- runs the teacher on the first 256 Qwen tokens of a text and writes ids and logits to `models/qwen_check.bin` for `tools/check_qwen.py`.
- `src/sample.c` (+ `sample.h`) -- held-out NELBO bits/byte, masked-token bits/byte, masked-fill accuracy and, in block mode, the clean rows' AR NLL, on fixed eval batches; `build/sample [checkpoint [diffusion|block<n>[d<D>]|ar]]`.
- `src/generate.c` (+ `generate.h`) -- generation over several rounds with quality statistics; `build/generate [steps [checkpoint [temp [mode [judge [policy]]]]]]`; modes `diffusion`, `block<n>` (cached block by block), `ar`; policies `random`, `ltr`, `conf`, `remdm<eta>`, `spec<k>`.
- `src/bench.c` (+ `bench.h`) -- GPU memory of the training config, both fp16 matmul kernels on every training shape, forward / forward+backward / step timing with a per-kernel profile, then decode timing; `build/bench [adamw|muon [batch [diffusion|block<n>[d<D>]|ar]]]`.
- `src/probe_coopmat.c` -- lists the device's cooperative-matrix configs.
- `src/probe_memory.c` -- lists memory heaps/types with GPU and host bandwidth per type.
- `src/probe_acts.c` -- for a checkpoint whose training went non-finite: finds a batch whose fp16 forward overflows, checks the fp32 forward, prints per-layer max activations.
- `src/test_matmul_f16.c` -- fp16 coopmat matmuls vs the scalar fp32 matmul, scaled fp16 operands, both kernels and layouts, partial tiles, the output stage.
- `src/test_grad.c` -- train vs inference loss, fp16 vs fp32 backward, finite-difference check of every param's gradient (tiny model, ref32, in diffusion, causal, block and split block mode), accumulation, AdamW, Muon vs a host Newton-Schulz, the overflow skip, one-block block mode equal to diffusion, block causality, the cached block model equal to the full one, and the byte-KD loss vs a host reference with its logit gradient vs finite differences.
- `src/test_tokenizer.c` (+ `test_tokenizer.h`) -- tokenizer file round trip, a toy BPE exercising Qwen's pre-tokenizer (contractions in both cases, space runs, single digits, a punctuation-prefixed word, a space before a newline) and the merge order, and the Unicode classes.
- `src/test_ckpt.c` -- checkpoint write/read round trip through memory, with and without moments, and a weights-only file (loads, refused for resuming).
- `shader/` -- one compute kernel per file.
